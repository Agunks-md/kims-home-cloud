Simpan file JSON Service Account Google Drive di folder ini.

Contoh nama file:
- account1-service-account.json
- account2-service-account.json

Cara mendapatkan:
1. Buka Google Cloud Console (https://console.cloud.google.com)
2. Buat project baru atau pilih project yang sudah ada
3. Aktifkan Google Drive API
4. Buka IAM & Admin > Service Accounts
5. Buat Service Account baru
6. Buat Key (JSON) dan download
7. Simpan file JSON di folder ini
8. Share folder Google Drive Anda ke email Service Account

PENTING: Folder ini di-.gitignore, jangan commit ke repository!
